Telecom Network Incidents Analysis
Descripción
Proyecto de análisis de incidencias de telecomunicaciones desarrollado con MySQL y Power BI.

Objetivo
Analizar incidencias de red, identificar tipos de fallas frecuentes y visualizar indicadores clave mediante dashboards en Power BI.
